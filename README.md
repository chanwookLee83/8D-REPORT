# 품질 대책서 · 8D Report PWA

자동차 품질 기준 8D 대책서와 특성요인도(Fishbone)를 작성하는 오프라인 PWA입니다.
설치형 앱처럼 사용할 수 있고, 모든 데이터는 브라우저(localStorage)에 저장됩니다. 서버가 필요 없습니다.

## 기능

- **기본정보** : 문서번호·고객사·부품·차종 등, 불량 유형(직접 입력), 불량 수량 / 고객 재고 / 사내 재고 / WIP 직접 입력
- **불량 사진** : 사진 업로드 후 불량 영역을 박스·원·화살표·펜으로 표시 → 번호 자동 부여, 번호별 내용 작성(8D D2에 자동 반영), 참고 사진 첨부
- **8D 리포트** : D0(비상조치·ERA) ~ D8(종결·팀 노고 치하) 전 단계
  - D2 : 5W2H · IS/IS NOT + 표시 영역 연동
  - D4 : 발생/유출 원인, 5-Why(발생·유출) 각 5단계 + 근본원인
  - D6 : 시정조치 실행 표
  - D7 : PFMEA·관리계획서·작업표준 등 개정 체크리스트 + 수평 전개
- **특성요인도** : 6M(사람·기계·재료·방법·측정·환경) 카테고리별 원인/하위원인 입력 → SVG Fishbone 자동 생성, PNG 저장
- **미리보기 / 출력** : 전체 보고서 A4 서식으로 조합, 브라우저 인쇄 → *PDF로 저장*
  - **문서 언어 : 국문 / English / 국·영문 병기** — 섹션 제목·라벨은 정적 사전으로 즉시 번역(오프라인). 서술 내용(D0~D8·5-Why·특성요인도)은 «🌐 영문 번역(AI)» 버튼으로 일괄 번역해 `report.i18n` 에 캐시(BYOK). 한글 수정 후 다시 누르면 갱신. 병기 모드는 각 항목에 한글+영문을 함께 출력(고객 검토용). 선택 언어는 브라우저에 기억되고 인쇄에도 반영.
  - **📷 AI 8D 분석·작성** : 온라인 + API 키 설정 시, **전체 불량 사진 + 각 표시 영역 확대 크롭 + 참고 사진**을 모두 Claude 비전으로 분석해 **8D 전체(D0~D8) + 5-Why + 특성요인도(6M)** 를 실제 제출용 대책서 문체로 작성(해당 항목 덮어씀, AI가 값을 낸 항목만). 부품 유형을 사출 성형품 / 조립품으로 판정해 각 계통(성형 조건 또는 삽입력·토크·압입·용착 수준)으로 원인·대책을 전개함. 표시 영역에 "미성형"·"단자 휨" 등을 적어두면 그 불량으로 확정함. 날짜·수량·LOT·인명은 지어내지 않고 `[확인]` 표기 — 직접 채워야 함. SSE 스트리밍, adaptive thinking, `max_tokens` 32000.
  - **🎯 AI 분석 범위 선택** (미리보기 탭) : 불량 개요 / D0 / D2 / D3 / D4+5-Why / D5 / D6 / D7 / D8 / 특성요인도를 개별 체크. 체크한 구획만 AI가 작성·덮어씀(선택은 브라우저에 기억). 기본 정보·사진은 작성자가 직접 입력.
  - **🧩 AI 분석 보조 정보** (미리보기 탭) : 발생 추세·금형/캐비티·재료 로트·성형/조립 조건 실측·최근 4M 변경점·유사 이력 등을 입력하면 AI 분석의 근거로만 사용(대책서 본문엔 인쇄 안 됨). 채울수록 D4/D5가 구체화됨.
  - **❓ 먼저 질문받기** : AI가 근본원인 확정에 필요한 질문 3~6개를 먼저 제시 → 답변 입력 후 그 답변까지 반영해 8D 작성.
  - **항목별 ✦ AI 보강** (8D 리포트 탭) : D4 발생/유출 원인 옆 «✦ AI 5-Why 전개» — 작성자가 적은 원인을 베이스로 해당 5-Why 체인만 인과 연결해 채움. D5 발생방지·유출방지·부작용/위험성·선정 근거 옆 «✦ AI 보강» — 작성자 초안 유지하며 해당 한 항목만 대책서 문체로 구체화(사진·표시영역·보조정보·현재 8D 상태를 근거).
  - **✍ 템플릿 작성 (오프라인)** : 입력값 기반 규칙 문장 초안. 키·네트워크 불필요, AI 폴백.
  - 미리보기 탭 › *🔑 AI 사진 분석 설정*에서 본인 Anthropic API 키 입력(이 브라우저에만 저장, api.anthropic.com 으로만 전송). **분석 깊이**(medium/high/xhigh)와 **2단계 분석**(사진 관찰 → 8D 전개, 더 정밀·2배 느림) 토글 제공. 모델 변경은 콘솔에서 `AI.setModel('claude-sonnet-5')`.
- 대책서 여러 건 관리, 복제, JSON 백업/복원

## 실행 방법

서비스 워커(오프라인 캐시)와 카메라 접근을 쓰려면 `localhost` 또는 HTTPS에서 열어야 합니다.

```powershell
cd "C:\Users\USER\quality-report-pwa"
python -m http.server 8080
```

브라우저에서 `http://localhost:8080` 접속 → 주소창의 **설치** 아이콘으로 앱 설치.

> 단순히 `index.html`을 더블클릭해도 대부분 기능은 동작하지만, 오프라인 설치는 위 방식으로 실행할 때만 가능합니다.

## 배포

`quality-report-pwa` 폴더 전체를 정적 호스팅(사내 IIS, GitHub Pages, Netlify 등)에 올리면 됩니다.
빌드 과정이 없습니다.
